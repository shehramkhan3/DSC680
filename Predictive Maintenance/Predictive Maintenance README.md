# Predictive Maintenance Telemetry Pipeline

## 📋 Overview
Engineered an end-to-end industrial machine learning pipeline across 10,000 sensor observations (temperature, rotational speed, torque) to detect catastrophic equipment failures before breakdown occurs and optimize plant economics.

---

## 🛠️ Tools Used
* **Python 3.x**
* **Machine Learning:** `scikit-learn`, `XGBoost`, `RandomForestClassifier`
* **Data Processing:** `pandas`, `numpy`
* **Visualization:** `matplotlib`, `seaborn`
