# Video Game Sales Exploratory Data Analysis (EDA)

## 📋 Overview
Extracted actionable industry trends and publisher performance metrics from a global dataset of 16,719 video game records, cleaning missing values and engineering regional sales percentage features.

## 🛠️ Tools Used

* **Data Cleaning & Manipulation:** `pandas`, `numpy`
* **Visualization:** `matplotlib`, `seaborn`
