# U.S. Retail Sales Time-Series Forecasting

## 📋 Overview
Forecasted macroeconomic retail sales trends and 12-month seasonality using historical monthly census data from January 1992 through June 2021 via exponential smoothing.

---

## 🛠️ Tools Used
* **Python 3.x**
* **Time-Series / Statistics:** `statsmodels` (Holt-Winters), `pandas`, `numpy`
* **Visualization:** `matplotlib`, `seaborn`
